# Silver Layer ETL Scripts

This folder contains AWS Glue ETL scripts for cleaning and transforming the raw Olist e-commerce datasets.

## Datasets

* Orders
* Order Items
* Customers
* Payments
* Reviews
* Products
* Sellers
* Geolocation
* Category Translation

## Processing

The Silver layer reads raw datasets from Amazon S3, applies data cleaning and transformations, and writes the processed datasets to the Silver layer in Amazon S3.

## Note

The actual ETL scripts will be added as they are collected and validated from the AWS Glue jobs.
